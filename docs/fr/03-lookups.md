# 03 — Tables de consultation

Les lookups prouvent qu’un tuple de valeurs appartient à une table déclarée.
Ils remplacent avantageusement certaines longues contraintes arithmétiques.
Un contrôle de plage peut ainsi être représenté par appartenance à un ensemble autorisé.
Le circuit doit néanmoins charger correctement la table et contraindre toutes les colonnes consultées.
Une table incomplète rejette des témoins valides ; une table trop permissive accepte des états indésirables.
Le mécanisme de permutation relie les occurrences sans révéler leur ordre d’origine.
Les lookups sont donc un outil d’expressivité autant qu’une surface d’audit.
La revue doit comparer le domaine métier attendu au domaine réellement encodé par la table.
